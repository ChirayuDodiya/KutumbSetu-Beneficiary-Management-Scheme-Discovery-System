# KutumbSetu - Beneficiary Management & Scheme Discovery System

KutumbSetu is a comprehensive government e-governance platform designed to streamline beneficiary management, automate scheme eligibility, and provide citizens with an AI-powered conversational assistant to navigate complex government guidelines.

## ✨ Key Features

### 1. Automated Scheme Eligibility Engine
Citizens create a "Family Profile" encompassing their income, caste, and residence. When they explore available benefits, an automated Rule Engine cross-references their profile against every scheme's JSON-based criteria, instantly tagging them as "Eligible" or "Not Eligible" (with explicit rejection reasons).

### 2. AI RAG Chatbot (Kutumbsetu AI)
Instead of forcing citizens to read massive PDF documents, the platform features a globally accessible floating AI chatbot.
* When the Admin creates a new scheme, they upload a Markdown (`.md`) file of the official guidelines.
* The backend instantly chunks the file and embeds it into a **Supabase pgvector** database using **LangChain** and **HuggingFace** sentence-transformers.
* Citizens can ask complex questions ("Can I apply for the housing scheme if my income is 2 lakhs?") and get highly accurate, grounded answers natively generated by a Groq-powered LLM.

### 3. Secure Document Vault & S3 Integration
Citizens have a "My Documents" vault where they can upload Aadhaar Cards, Income Certificates, etc.
* Files are uploaded directly to a secure **Supabase S3 Object Storage Bucket**.
* When applying for a scheme, citizens are dynamically prompted to link a specific document from their vault to satisfy the scheme's requirements.
* Officers reviewing the application get clickable links to instantly view the securely hosted documents.

### 4. Global DOM Translation (English / Gujarati)
Designed for accessibility, a global translation toggle (`Globe` icon in the navbar) injects a Google Translate DOM script to instantly translate the entire React application into Gujarati. Simultaneously, the backend LLM system prompt is dynamically updated to reply exclusively in native Gujarati.

### 5. Admin Analytics Dashboard
The System Admin can monitor the performance of all active schemes via a live statistical dashboard tracking:
* Total Allocated Budget
* Number of Applications Submitted
* Total Approved vs. Rejected Applications

## 🛠️ Tech Stack

* **Frontend:** React, Tailwind CSS, Lucide React, Vite
* **Backend:** Node.js, Express.js, PostgreSQL (pg)
* **AI / ML:** LangChain, Groq LLM API, HuggingFace Inference Embeddings, pgvector
* **Storage:** Supabase PostgreSQL Database, Supabase S3 Object Storage Bucket
* **Translation:** Google Translate DOM Injector

## 🚀 How to Run Locally

1. **Install Dependencies:**
   - In the `Backend` folder: `npm install`
   - In the `Frontend` folder: `npm install`
2. **Setup Environment:**
   - Ensure the `.env` file at the root contains your Supabase URL, Groq API Key, HuggingFace API Key, and AWS S3 credentials for Supabase.
3. **Start the Servers:**
   - Backend: `npm run dev` (Runs on port 5000)
   - Frontend: `npm run dev` (Runs on port 5173)
